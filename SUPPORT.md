# Support

## Using hackathon.new

Check the [documentation](https://hackathon.new/docs) first. For reproducible
bugs or focused feature requests, open a GitHub issue using the matching form.

GitHub issues are public. Remove names, email addresses, event access links,
API keys, logs with tokens, and other private data before posting.

## Security and private data

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md)
and use GitHub's private vulnerability reporting flow.

## Community expectations

This is a community-supported open-source project. Response times are not
guaranteed. Clear reproduction steps and a small example make help easier.
