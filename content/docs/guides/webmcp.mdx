---
title: Work with a browser agent
description: Use WebMCP to plan and prepare hackathon work while you keep the final say.
---

hackathon.new can share clear tools with an AI agent in your browser. Signed-in tools can find your events from anywhere in the app. Other tools match the page, your role, and the event's current step.

The agent can read the page, fill visible fields, and open a review. You still click the final button for actions that send, submit, publish, claim, or finish work.

## Create an event

Ask your agent to open the event builder from any signed-in page. Then it can:

- Read one part of the saved draft.
- Update fields in the visible editor.
- Open the full event review.
- Open sign in while keeping your draft saved.

The agent can't create the event. Check every section, then click **Create Event**.

## Join and submit

From any signed-in page, an agent can list events you're attending. It can read the rules, schedule, updates, released challenges, team status, and project status. It can also prepare a project and open the normal review on your current page.

On the event page, it can also open registration, fill a team invite, or prepare a mentor request.

You accept terms, share location when needed, and click the final button.

## Run an event

Organizers can ask an agent to find an event, read its to-do list, and open any section from anywhere in the app. On any manage tab, it can edit basic details, add a normal schedule item, prepare a sponsor, or draft an announcement. Judging prizes can be added after publication while scoring rules remain editable.

Supported organizer actions can run directly when authorized. The server checks event state and permissions before each action. Tools return clear saved, queued, failed, or conflict outcomes.

### Judging setup tools

The Judging pages and Action Items provide task tools:

- `inspect_judging`: Read readiness, dates, scorecards, invitations, rounds, and progress.
- `configure_judging`: Save dates and preferences or explicitly apply the starter setup.
- `save_judging_prize` and `save_judging_category`: Create or edit prizes and scorecards.
- `save_judging_round`: Configure an optional round and its dates.
- `invite_judging_panel`: Preview or send invitations, with results for each recipient.
- `remind_judging_panel`: Check reminder eligibility or nudge judges with unfinished work.
- `preview_judging_work` and `apply_judging_work`: Review and apply balanced assignments.
- `inspect_judge_scope` and `save_judge_scope`: Read and set a judge's prizes and rooms.
- `inspect_judge_projects` and `assign_judge_project`: Inspect eligible projects and adjust one assignment.
- `open_judging_settings`: Open the matching judging page.

Inspect first to get the current configuration version. Reuse a request key when retrying a save or assignment operation. Invitation previews do not send email; draft-event sends are queued. Retry only failed recipients. Tool lists are paged to keep results small.

## Judge projects

A judge can list their assigned projects, open one project, and prepare the response style set by the organizer. hackathon.new supports scores, ranked picks, sort groups, and yes-or-no checks.

Prepared answers use the same private draft saving as the review form. They affect results only after the judge submits the review.

## Help as a mentor

Visitors can see only the number of requests waiting, in progress, or done. Verified mentors can read a small part of their queue and open the normal claim or finish review. Request text is never public.

The mentor makes the final click for every claim and finish action.

## Safety

- hackathon.new checks your login, role, event state, and access again on the server.
- Page tools stop working when you leave the page. Workspace tools recheck your role and current event state each time.
- Private records use short page-only references instead of database IDs.
- User and project text is marked as untrusted.
- Tool results stay small and use clear success or error shapes.

WebMCP is an early browser feature. Learn more in the [Chrome WebMCP guide](https://developer.chrome.com/docs/ai/agents) and [tool security guide](https://developer.chrome.com/docs/ai/webmcp/secure-tools).
