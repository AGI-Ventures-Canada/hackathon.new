---
title: Work with a browser agent
description: Use WebMCP to plan and prepare hackathon work while you keep the final say.
---

hackathon.new can share clear tools with an AI agent in your browser. The tools match the page, your role, and the event's current step.

The agent can read the page, fill visible fields, and open a review. You still click the final button for actions that send, submit, publish, claim, or finish work.

## Create an event

Open `/create`, then ask your agent to help build the event. It can:

- Read one part of the saved draft.
- Update fields in the visible editor.
- Open the full event review.
- Open sign in while keeping your draft saved.

The agent can't create the event. Check every section, then click **Create Event**.

## Join and submit

On an event page, an agent can explain the event and your current status. When the next step is ready, it can open registration, fill a team invite, prepare a project, or prepare a mentor request.

You accept terms, share location when needed, and click the final button.

## Run an event

Organizers can ask an agent to read setup progress, open a section, edit basic details, add a normal schedule item, or draft an announcement. Draft events can also get new dates, challenges, and prizes.

The agent can't go live, send an announcement, pick winners, publish results, or delete event data. It opens the normal review so an organizer can decide.

## Judge projects

A judge can list their assigned projects, open one project, and prepare the response style set by the organizer. hackathon.new supports scores, ranked picks, sort groups, and yes-or-no checks.

Preparing a response doesn't save it. The judge checks the visible controls and clicks the normal save button.

## Help as a mentor

Visitors can see only the number of requests waiting, in progress, or done. Verified mentors can read a small part of their queue and open the normal claim or finish review. Request text is never public.

The mentor makes the final click for every claim and finish action.

## Safety

- hackathon.new checks your login, role, event state, and access again on the server.
- Tools stop working when you leave the page or your role or event state changes.
- Private records use short page-only references instead of database IDs.
- User and project text is marked as untrusted.
- Tool results stay small and use clear success or error shapes.

WebMCP is an early browser feature. Learn more in the [Chrome WebMCP guide](https://developer.chrome.com/docs/ai/agents) and [tool security guide](https://developer.chrome.com/docs/ai/webmcp/secure-tools).
