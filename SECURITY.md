# Security Policy

## Report a security issue

Please do not open a public issue for a security problem.

Use [GitHub's private vulnerability report](https://github.com/AGI-Ventures-Canada/oatmeal/security/advisories/new) and include:

- what you found;
- how to reproduce it;
- what an attacker could access or change; and
- any suggested fix.

We will confirm receipt, investigate the report, and share next steps through the private advisory.

## Supported version

Security fixes are applied to the latest release on `main`.
