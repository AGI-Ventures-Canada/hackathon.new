# Security Policy

## Report a security issue

Please do not open a public issue for a security problem.

Use [GitHub's private vulnerability report](https://github.com/AGI-Ventures-Canada/hackathon.new/security/advisories/new) and include:

- what you found;
- how to reproduce it;
- what an attacker could access or change; and
- any suggested fix.

We will confirm receipt, investigate the report, and share next steps through the private advisory.

Please give us a reasonable chance to fix the issue before sharing it publicly.
Do not access data that is not yours, disrupt the service, or use automated tests
that could harm other users. Good-faith research that follows these rules will
not be met with legal action from us.

## What to include

- The affected URL, commit, or package version
- A minimal proof of concept
- The impact and required user role
- Any logs or screenshots with secrets and personal data removed

Do not send credentials, access tokens, private keys, or real user data.

## Supported version

Security fixes are applied to the latest release on `main`.
